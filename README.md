# MathPlot v2 — Equation Visualizer

Fully responsive, animated, cyan-black themed React app with Tailwind CSS.

## 🚀 Setup

```bash
npm install
npm start
# Opens at http://localhost:3000
```

## ✨ What's New in v2
- Full **Tailwind CSS** — no custom CSS files
- **Responsive** — works on mobile, tablet, desktop
- Mobile **drawer sidebar** with hamburger menu
- **Animated** background grid, scan-line, ambient orbs, neon flicker, glow-pulse
- Improved **color grading** — deep teal-cyan gradient theme
- **Corner accents** on graph panel
- **Graph line glow** via SVG drop-shadow filter
- **Auto-rotating tips** in InfoBar
- **Color swatches** for quick curve color picking
- Better **graph sizing** — not stretched on desktop

## 📐 Syntax

| Input | Meaning |
|-------|---------|
| `sin(x)` `cos(x)` `tan(x)` | Trig |
| `asin(x)` `acos(x)` `atan(x)` | Inverse trig |
| `sinh(x)` `cosh(x)` `tanh(x)` | Hyperbolic |
| `e^x` or `exp(x)` | Exponential |
| `log(x)` | Natural log |
| `log10(x)` | Base-10 log |
| `sqrt(x)` | Square root |
| `abs(x)` | Absolute value |
| `floor(x)` `ceil(x)` | Round |
| `x^2` `x^3` | Powers |
| `pi` `e` `phi` `omega` `tau` | Constants |
